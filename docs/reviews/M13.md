# M13 —— 收盘后先出临时结果，次日定稿

计划：[`docs/provisional-close.md`](../provisional-close.md)。分支 `m13-provisional-close`。

## 一、起因

2026-09-29、09-30 两天当天都没有数据。M12 的原则「宁可晚几小时，不要一个会变的数字」
加上数据源 22:15 ET 才结算、GitHub cron 迟到 3 小时以上，结果是当天什么都没有。
用户决定改原则：**收盘后尽快出一个标明临时的结果；正式收盘价一到就修正；前一天及
更早的历史必须是定稿数字。** 用户同时确认：当晚能定就定、次日兜底；兜底先 Stooq 再告警；
M12 BACKLOG 里那条 force 挑错 session 的 bug 并进本里程碑。

实测依据（2026-10-01）：17 只 × 9-22…9-30，1 分钟线最后一根 vs 正式收盘价，
中位数 1.0–2.4 bp，最大 22 bp；同日 `Adj Close` = `Close`。用真实数据冒烟
`_settle_prices`（9-30 当成收盘 +65 分钟、去掉当天日线）：17/17 补齐，中位数 2.0 bp。
