## 实跑抓到的、单元测试抓不到的五件事

### 1. `not null default '{}'` 的两列

`extra` 与 `provisional_metrics` 是 `not null default '{}'`。
**「有默认值」只在*不提供该列*时生效** —— 提供了 NULL 就是 NULL。
第一次回填直接撞 NOT NULL。（T2 完整回滚，符合设计。）

### 2–4. 差分写入的三层精度问题

§7.3.1 要求「只 upsert 与库里真正不同的行」。三次实测才收敛：

| 做法 | 结果 |
|---|---|
| 直接比 float | **6698/6800 行都「变了」** —— 写入优化完全失效，且复权因子探测器**每一跑都误报** |
| 各自 `round(f, 4)` 再比 | 仍有 513 行误判：跨在舍入边界两侧的两个值会被推开一整个 ulp |
| 对原值取半 ulp 容差 | 仍有约 550 行每跑都「变」，且**不收敛** |

根因实测出来了：**yfinance 的 `Adj Close` 只稳定到 float32。**
同一只股票、同一天、同一窗口，两次调用给出
`97.33495330810547` 与 `97.33494567871094`，差 7.6e-6。
存储是 4 位小数，真值只要落在某个 `.00005` 边界 7.6e-6 以内，
这点噪声就会把第 4 位翻过去 —— 随机值落进那条缝的概率约 7.6%，
而实测正是 8.5%。

→ 差分改判「**看起来会不会不一样**」：一个存储刻度或供应商噪声以内都算没变。
实测收敛到 0 行。

### 5. 孤儿行不变式在接线的第一分钟就还本了

事件刚接进管道，17 个标的里 **14 个**报「有 2 条未来财报行」。
原因：`Ticker.calendar` 与 `Ticker.earnings_dates` 对**同一件事**
给出相差一天的日期（AAPL：10-30 vs 10-29）。

这正是 §3.5(1) 那条不变式要防的后果：`days_to_next_earnings` 取
`min(未来 event_date)` 会指向更早的那个，到期后翻成「财报后 1 天」——
**播报一场从未发生的财报**，再过一天数字又自己对了，事后更难发现。

## 闸门 A

### M4 基础层（两组 agent）

1 条 SERIOUS：`Retry-After` 被截断到 60 秒。§7.3.1 里的「上限 60s」说的是
**我们自己算的**指数退避，不是对方给的指令。对方说等 300 秒、我们 60 秒
就回去敲门，正是这条规则要防的明知故犯，而且与那段代码自己的注释
「猜错的方向是等得太短」直接矛盾。

**突变测试抓到 4 条「会跟着代码一起坏掉的测试」**：退避上限那条注入的抖动
恰好是 1.0，所以 `min()` 放哪边都通过；所有重试测试都用 `interval=0`，
所以双重 sleep 的错误实现能完整通过；`diff_sessions` 的「今天」边界
一条测试都没有，而把 `<=` 改成 `<` 能全绿。

### M4 写入层（一组 agent）—— **5 条 SERIOUS，3 条是静默错数**

| | 坏掉的东西 | 症状 |
|---|---|---|
| S1 | `provisional_metrics` 按**窗口**算而不是按**行**算 | **生产库 6800 行全是空的**，§10.4 的灰标在任何地方都不出现 |
| S2 | alpha/beta 按**位置**配对而不是按**日期** | 一个内部空洞 → beta 差 2.6 倍、R² 差 6.8 倍，而 `n_obs` 仍报 126 |
| S3 | `mom_20` 数 20 **行**而不是 20 个 **session** | 21 session 的动量存在 `mom_20` 名下，而它是排名分 |
| S4a | 闸门 3 排除的标的被「丢掉」而不是「写 NULL」 | 昨天那行成为最新行，带着八个事件列 → 不变式当天变红 |
| S4b | 过滤后没有重新检查空集 | 供应商全线故障 + 一次 `--force` **会静默删掉当天榜单** |
| S5 | 日历历史修订静默通过 | `ok` / exit 0 / 不告警，而 §9.1.4 第 5 条明写要记 partial |

同轮还发现：T1 那个「留下 running 行」的信号**没有任何消费者**
（`_already_done` 只匹配 ok），而 `daily.yml` 有 30 分钟超时 ——
超时被杀时写下的恰恰是那一行没人看的记录。已补第 19 条不变式。

`run_daily` / `store` 的写入契约此前**一条测试都没有**，四个突变能活下来。
