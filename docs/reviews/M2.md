## 闸门 A — review agent

**3 项 SERIOUS，全部经实测复现。**

| # | 发现 | 处置 |
|---|---|---|
| S1 | **一个缺失价格被伪造成「平盘日」。** `NaN > 0` 与 `NaN < 0` 都是 False，所以朴素的 `np.where` 产出 `gain=0, loss=0` —— 恰好是本模块自己的 docstring 与 §3.1 明令禁止的「用 0 冒充」。而 Wilder 是 IIR 递归，**污染永不消散**：reviewer 实测，单个缺失日让其后每一天的 RSI 都偏向那次缺失的方向（`[…, 12, NaN, 11.5, …]` 干净值 64.44 → 污染后 83.33）。这不是假想：§7.3.1 的批量 `yf.download` 在某标的缺一天时返回的就是 NaN。而这个值是**有限的**，M4 的 NaN sanitizer 拦不住 | 已修 → `np.isnan` 掩码，让 NaN 毒化递归。补 RSI / EMA / momentum 三条 NaN 传播测试 |
| S2 | **「拆股连续性」验收测试里根本没有拆股。** 夹具是一条 `+1/天` 的线性斜坡（`set(np.diff(adj)) == {1.0}`），断言的是「平滑的斜坡是平滑的」。§11 那条标准等于没有测试 | 已修 → 真 2:1 夹具（第 80 根后价格砍半）。测试**先断言夹具里确实有断崖**（`raw_jump < -0.45`），再断言复权列连续、且未复权分子会暴露断崖 |
| S3 | **退化守卫紧了四个数量级，垃圾 t 值仍可达。** `ssr <= 1e-20 * sst` 即 `R² ≥ 1-1e-20`，而 float64 里严格小于 1.0 的最大数其 `1-R²` 是 `1.11e-16`。实测：噪声 σ=1e-10 时 `SSR/SST = 1.77e-17`，守卫**不触发**，`alpha_t_stat = 1.26e8` —— 而 `abs(1.26e8) < 2` 为假 → 那一行**不打灰** → UI 宣称统计显著 | 已修 → 放宽到 `1e-12`（没有任何两只美股的 126 日回归能达到 `R² > 1-1e-12`），并加一道 `\|t\| ≤ 50` 的合理性天花板 |

**11 项 MINOR 全部采纳**，其中改变行为的几条：
`r2` 原本由 `corr*corr` 导出，使 `r2 == corr²` 那条测试**永远不可能失败** →
改为 `1 - SSR/SST` 独立计算，恒等式才成为真的不变式；
「QQQ 对自己」的头号验收测试只走了 `is_benchmark` 短路（返回字面量），
**回归路径本身从未被测过** → 补 `is_benchmark=False` 的版本；
`is_benchmark` 分支绕过了 `min_obs`，首次回填那天 QQQ 会在 **0 个观测值**上
断言完整的 α/β/R² → 样本量检查前置；
`ssr/(n-2)` 在 `n=2` 时除零 → `min_obs < 3` 直接报错且信息指向 config 键；
`is_squeaky` 对全池同值的池按 `np.mean` 能否恰好整除给出**相反结论**
（3 个标的答 True、4 个答 False）→ 真并列在归一化前判定为 True，那也是语义上正确的答案；
`events.py` 的 `min`/`max` 在同日重复行上取「列表里的第一个」，而 `symbol_events`
**故意没有自然主键**、`SELECT` 无 `ORDER BY` 无顺序保证 → 显式打破并列，同日优先取已确认行；
`alpha_beta` 挂在 `kind="series"` 下却是第三种签名 → 新增 `kind="pairwise"`；
`METRIC_KINDS` 是个穿着常量名字的死函数 → 重命名并接进测试；
`config` 的 `derived.expr` 与 `ema.py` 是两份未对齐的定义、且已在除零处不一致
→ 声明 Python 实现为权威、`expr` 仅作文档。

## 闸门 B — codex CLI

**又一个 SERIOUS，是同一类疏忽的另一半。**

| # | 发现 | 处置 |
|---|---|---|
| C1 | `session_returns` 给**分母**加了 `> 0` 守卫，却没给**分子**加。实测 `[100, 0, 101, -2, 102]` → `[NaN, -1.0, NaN, -1.0198, NaN]` —— 两个**看起来完全正常**的日收益静悄悄进入 OLS。它们是**有限值**，§9.1.3 的 NaN sanitizer 拦不住 | 已修 → 分子分母都查 `notna() & (> 0)`；用 reviewer 的原始复现例做测试 |
| C2 | `\|t\| > 50` 那条天花板的测试**从未到达它要测的分支** —— 1e-9 噪声让 `SSR/SST ≈ 2e-15`，落在 1e-12 的退化分支里，是上一道守卫在起作用 | 已修 → 构造 `SSR/SST = 2e-12`（退化阈值之外），断言 `r2 < 1-1e-12`、残差波动非零、且 t 值仍被写成 None。codex 独立复测：实际 ratio `1.9997e-12`，未封顶的 t ≈ 375,911 |

codex 还提了一个**框架性意见**并被采纳：`|t| ≤ 50` **是产品策略，不是数值定理** ——
一个噪声极低但数学上完全合法的过程确实可能超过它并被抹掉。
模块注释已改为如实陈述这一点，并记下为什么在本项目的具体场景里接受这个代价，
以及「单靠 R² 阈值界不住 |t|」的实测证据（`SSR/SST = 1.01e-12` 时 t 仍达 4.9e5）。

第二轮：**clean，无 SERIOUS。**

## 顺带更正的设计文档

§10.3「名次胶着」阈值的**方向原本是反的**。把算术摆出来：
平静期 16 只标的铺开 2pp，相邻间隔约 0.13pp，**小于**固定的 0.5pp → **一直触发**；
高离散期铺开 25pp，间隔约 1.5pp → **永不触发**。
原文写的是「前一种永不触发、后一种一直触发」。

更正后的表述：固定阈值**在最不需要提醒的时候最吵，在真正该提醒时沉默**。
归一化后的语义也更合理：**同样的绝对间隔，在密集的池里是真分开了，在铺得很开的池里只是噪声。**
测试相应改成尺度不变性断言（全池得分乘任意常数，结论不变）——
那正是固定 pp 阈值必然翻车的地方。

这个错是**写测试时被逼出来的**：期望值按原文写就跑不通。
